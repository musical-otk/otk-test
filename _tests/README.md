# mu:di 허브 테스트

허브(otk-test → otk-schedule)를 고친 뒤 원본에 반영하기 전에 돌린다. `_` 로 시작하는 폴더라 GitHub Pages 에는 공개되지 않는다.

## 돌리는 법

```bash
# 1) 로컬 서버 (D:\workspace 에서)
python -m http.server 8765 --bind 127.0.0.1

# 2) 동작 테스트 (크롬 필요 — playwright, channel='chrome')
PYTHONIOENCODING=utf-8 python _tests/pw_full.py <스크린샷폴더>
PYTHONIOENCODING=utf-8 python _tests/pw_backup.py <다운로드폴더>
PYTHONIOENCODING=utf-8 python _tests/pw_features.py <스크린샷폴더>

# 3) 정적 검사 (deno lint)
python _tests/lint.py
#    (require-await 3건은 알고 있는 스타일 지적)
```

모두 `SUMMARY n / n` 이어야 한다. `sw.js` 의 CACHE_NAME 을 올리는 것도 잊지 않는다.

## 무엇을 넣나

- 요청으로 바뀐 동작 중 **다시 깨질 수 있는 것**만 넣는다(규칙·저장·옮기기·표시 조건).
- 문구 한 줄, 한 번 보면 되는 모양(아이콘 여백 등)은 그때 확인으로 끝낸다.

- 날짜 상세에도 남음
- 사진만 있는 회차가 날짜 상세에 나옴

- m.diary → 달력

- 동기화 후 오류 없음

- 페이지 오류 없음

### 요청별 기능 (pw_features.py)

- 달력 버튼 순서 [전체 회차][내 기록]
- 스와이프 왼쪽 → 다음 달, 오른쪽 → 돌아옴
- 세로로 밀면 안 넘어감
- 주간 스와이프는 한 주
- ‹ › 누르면 미끄러지는 효과
- 미끄러질 때 가로 스크롤 안 생김
- 눈금 안내 문구
- 사진만 있는 회차는 칠하지 않음·사진 점 없음
- 날짜 상세 이벤트 → 이벤트 창
- 날짜 상세 이벤트 → 이벤트 창 (11/11 소크라테스 이벤트 필요)
- 이벤트 설명 줄바꿈(문장 끝·—·/), 숫자 뒤 점은 그대로
- 설명 속 꺾쇠가 보이게
- 찾기 목록: 공연 중 / 공연 예정
- 지난 회차 10개씩 펼치기
- 지난 회차 접기
- 예매 수 오른쪽 정렬·두 칸 폭
- 관심함 ON/OFF 토글
- 같은 값이면 자동으로 되돌림(저장 없음)
- 막공 1주 뒤 자동 OFF
- 페이지 오류 없음 (1)
- 기타 → 작품으로 옮긴 공연(H.WINTER): 예매·좌석·메모가 따라옴
- 페이지 오류 없음 (2)
- 기타 정리: 기록 없으면 뺌
- 기타 정리: 기록 있으면 ♥ 없이 예매 회차만
- 내 달력: 처음엔 접힘
- 내 달력: 회차 없는 날은 흐리게(테두리 없음)
- 내 달력: 내 일정 있는 날에 작품 아이콘
- 내 달력: 날짜 누르면 그날 정리(내 일정·회차 캐스팅)
- 내 달력: 목록에서 보기 → 그날 회차로
- 내 달력: 배우 필터면 그날 회차 숨김 수 표시
- 내 달력: 다른 작품에서도 펼친 채
- 이벤트 줄임말(내 달력용)
