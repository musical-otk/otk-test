# mu:di 허브 테스트

허브(otk-test → otk-schedule)를 고친 뒤 원본에 반영하기 전에 돌린다. `_` 로 시작하는 폴더라 GitHub Pages 에는 공개되지 않는다.

## 돌리는 법

```bash
# 1) 로컬 서버 (D:\workspace 에서)
python -m http.server 8765 --bind 127.0.0.1

# 2) 동작 테스트 (크롬 필요 — playwright, channel='chrome')
PYTHONIOENCODING=utf-8 python _tests/pw_full.py <스크린샷폴더>
PYTHONIOENCODING=utf-8 python _tests/pw_backup.py <다운로드폴더>
PYTHONIOENCODING=utf-8 python _tests/pw_features.py <스크린샷폴더>
PYTHONIOENCODING=utf-8 python _tests/pw_import.py <스크린샷폴더>   # 다른 앱 기록(CSV) 가져오기 — 가짜 샘플 import_sample.csv, 이끼숲 앱 src 필요

PYTHONIOENCODING=utf-8 python _tests/pw_origin.py   # 다른 주소에서 열기 — 먼저: python -m http.server 8766 --bind 127.0.0.2

# 3) 정적 검사 (deno lint)
python _tests/lint.py
#    (require-await 3건은 알고 있는 스타일 지적)
```

모두 `SUMMARY n / n` 이어야 한다. `sw.js` 의 CACHE_NAME 을 올리는 것도 잊지 않는다.

## 무엇을 넣나

- 요청으로 바뀐 동작 중 **다시 깨질 수 있는 것**만 넣는다(규칙·저장·옮기기·표시 조건).
- 문구 한 줄, 한 번 보면 되는 모양(아이콘 여백 등)은 그때 확인으로 끝낸다.

### 다른 앱 기록(CSV) 가져오기 (pw_import.py)

실제 기록 파일은 개인 정보라 저장소에 넣지 않는다. 샘플은 가짜 데이터.

- 기본 기간은 올해부터
- 빈 줄 3개는 넣지 않음
- 이끼숲·소크라테스·사춘기는 회차에 맞춤
- 같은 작품 다른 시즌(곤 투모로우 2016·2023)은 공연 일정
- 띄어쓰기 다른 제목도 작품 인식(여신님이 보고계셔)
- 아직 확인 안 한 전용 앱(V에버애프터)은 공연 일정
- 올해부터 고르면 지난해 줄은 기간 밖
- 이끼숲 앱 기록에 들어감(좌석·가격·메모·캐스팅)
- 1층 B구역 2열 7번 → 앱 1층 2열 7번 + 메모 B구역
- 정보만 작품(소크라테스) 예매 기록 + 메모
- 예매만으로는 ♥ 안 누름
- 없는 작품은 🎭 공연 일정(좌석·여러 줄 메모)
- 못 읽는 좌석은 메모에 원문
- 같은 파일 다시 가져오면 새로 넣을 것 0
- 지운 것은 저절로 안 살아남
- 가져오기 되돌리기 보관
- 직접 입력과 같은 회차는 이미 기록 있음
- 이끼숲 앱이 오류 없이 열림
- 이끼숲 앱 화면에 가져온 좌석
- 허브 페이지 오류 없음
- 내 일정에 같은 날·시간·이름이 있으면 건너뜀
- 띄어쓰기만 다르면 같은 이름(가상 콘서트=가상콘서트)
- 띄어쓰기 말고 다르면 다른 이름(가상의 연극≠가상의 연극!)
- 같은 날 같은 이름이라도 시간이 다르면(낮·밤) 다른 공연

### 다른 주소에서 열기 (pw_origin.py)

- 사이트 주소 = 지금 열린 주소

- 앱 기록 읽음
- 앱 스케줄 읽음
- 앱 화면도 지금 주소에서 열림
- 옛 주소로 나가는 요청 0
- 페이지 오류 없음
